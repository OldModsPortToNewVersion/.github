# OldModsPortToNewVersion — оформление организации

Публичный профиль организации находится в [`profile/README.md`](profile/README.md).
GitHub показывает этот файл на странице организации, если репозиторий называется `.github`.

## Обложка: глава Legacy

Первая карточка использует **реальные PNG-изображения**: таумометр и банку
из Thaumcraft 4, дробитель IndustrialCraft 2, ME Drive из первого Applied
Energistics, карьер BuildCraft, пасеку Forestry и официальный логотип
LavaCraft.ru. Оформление, подставки и движение заданы SVG; предметы не перерисованы.

Изображения хранятся в `profile/assets/originals/`. Банка вырезана из таблицы
спрайтов по координатам статьи. Таумометр и ME Drive выделены из игровых
изображений 2014 и 2013 годов по внешнему контуру. Для пасеки использован
рендер 128 × 128 из старой вики, загруженный в 2013 году.
Изображения встроены в SVG как PNG data URI, поэтому карточка не зависит от
загрузки сторонних сайтов. Для небольших спрайтов включено pixelated-масштабирование.
Это анимированная композиция из игровых изображений, не запись геймплея.

Ссылки, авторство и ограничения точности версий: [ASSET_SOURCES.md](ASSET_SOURCES.md).
Машиночитаемый манифест содержит URL, прямоугольники обрезки, размеры и SHA-256.

Текущая карточка показывает старые образы. Сравнение старой и новой версии
можно будет добавить следующей главой, когда появятся конкретные порты.

### Движение

- Общее вступление длится около двух секунд.
- Через 2.4s начинается девятисекундный цикл: изображения слегка парят
  в первой половине, затем следует спокойная пауза. Тексты неподвижны.
- Используется native SVG/SMIL. Скриптов и внешних ресурсов внутри SVG нет.
- Для reduced motion формируется отдельная законченная статичная композиция.
- Светлая и тёмная темы, адаптация до 600px ширины изображения.

### Сборка

```sh
python scripts/build_cover.py
python -m unittest discover -s scripts -p 'test_*.py' -v
python scripts/verify_cover.py --output /path/to/review
```

Генератор использует стандартную библиотеку Python. `scripts/fetch_images.py`
нужен только для повторной загрузки источников и требует Pillow. Обычная
сборка работает офлайн и проверяет SHA-256 локальных PNG. Для визуальных проверок
нужны Playwright, установленный Chromium и Pillow. SVG редактируются через
`scripts/build_cover.py`, `scripts/relics.py` и `scripts/svg.py`.

`verify_cover.py` создаёт кадры вступления, изображения обеих тем, GIF
и локальное HTML-превью. Эти файлы не нужны для отображения на GitHub.
